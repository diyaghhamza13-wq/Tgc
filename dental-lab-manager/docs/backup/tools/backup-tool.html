Dental Lab Manager — offline backup tool

Everything happens in this browser. The page cannot connect to the internet (its security policy forbids it). Nothing is saved: closing the page erases keys and decrypted data.

1. Create your key pair (once)

2. Verify a backup (quarterly drill) and, if needed, create the restore SQL

3. Decrypt a single file (file map or a stored file)

Uses the private key pasted in section 2.
