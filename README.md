# WeCAD website demo

A responsive, multi-page front-end prototype for the WeCAD digital dental design platform.

## Run locally
Open `index.html` in a modern browser. For best results, serve this folder with a local static server (for example VS Code Live Server).

## Included
- Nine navigable sections: Home, Dashboard, My Profile, Orders & Files, Messages, New Order, Payments, Price List, About Us.
- Responsive desktop/mobile navigation.
- Dental order form with tooth selection and multi-file selection preview.
- USD standard price list.
- Demo chat, delete confirmation, profile form and payment proof selection.

## Important
This is a front-end prototype. Authentication, permanent data storage, real order submission, real messaging, payment processing, invoice generation, and secure file storage are not connected. These require a backend, database, authentication provider, and payment gateway. Demo values and example orders are placeholders.
